# jwst-galaxy-entropy
Code and data analysis for the phenomenological model of entropy dissipation in early galaxies (z > 9).
Источники данных и воспроизводимость:

Файл asu.tsv (уже загружен в репозиторий) — это официальная сырая выгрузка фотометрического каталога JADES (JWST Advanced Deep Extragalactic Survey), скачанная напрямую из астрономической базы данных VizieR (CDS). Файл не подвергался ручным изменениям и содержит исходные координаты и фотометрические красные смещения.

Для полной работы скрипта необходимо дополнительно скачать каталоги физических параметров CANDELS (Santini et al., 2015) из официального архива MAST:

hlsp_candels_hst_wfc3_goodss_santini_v1_mass-cat.fits

hlsp_candels_hst_wfc3_goodss_santini_v1_physpar-cat.fits

Поместите оба скачанных файла .fits в корневую директорию репозитория рядом с файлом asu.tsv и скриптом Python. После этого код можно запускать для автоматического получения выборки из 61 галактики.

Описание алгоритма и методология:
Данный репозиторий содержит скрипт для эмпирической валидации модели, представленной в статье. Он выполняет кросс-матчинг фотометрических кандидатов ранней Вселенной (z > 9) из обзора JADES с физическим каталогом CANDELS.Для получения строгой и надежной выборки, а также для исключения ложных пространственных наложений (spurious matches), в коде применены следующие физические и геометрические фильтры:Наличие посчитанной звездной массы и темпа звездообразования ($M_* > 0$, $SFR > 0$) в каталоге CANDELS.Жесткий радиус пространственного совпадения координат телескопов JWST и Hubble: 0.5 угловой секунды.Применение этих ограничений отсекает пространственный шум и оставляет подтвержденную выборку ровно из 61 массивной галактики. Именно эта база данных используется в статье для последующих расчетов диссипации энтропии и доказательства механизма "термодинамического клапана".
